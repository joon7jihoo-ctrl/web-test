# 한전KDN 홍보 웹페이지

풀스텍 바이브코딩 실습 웹사이트 — **한전KDN 홍보 페이지**

## 📁 파일 구조

```
web-test/
├── index.html   # 메인 HTML 페이지
├── style.css    # 전체 스타일시트
├── script.js    # 인터랙션 (카운터, 스크롤 효과, 폼)
└── README.md
```

## 🚀 실행 방법

`index.html`을 브라우저로 열기만 하면 됩니다.

## ✨ 주요 기능

- 반응형 디자인 (모바일/태블릿/데스크탑)
- 파티클 히어로 섹션
- 스크롤 숫자 카운터 애니메이션
- Intersection Observer 기반 스크롤 리빌 효과
- 모바일 햄버거 메뉴
- 연락처 폼 (UI 데모)
